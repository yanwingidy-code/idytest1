🔒 要連接住 Google Drive先可以開始核對。全部核對記錄會即時同步Drive；如果中途斷線／登入過期，會暫停畀你繼續，直到重新登入為止。
👤 同事授權管理（得你先睇到呢個部分）
你自己（）一直都有權限，唔使加入呢個清單。
加新同事，要跟足呢4步（跟錯次序，佢會見唔到你嘅資料）：
  1. 喺呢個app加佢個email
    落面個「一行一個email，或用逗號分隔」格度，貼佢個Google email（多過一個同事就一行一個），撳下面「儲存同事名單」。
  2. 去 Google Cloud Console 加佢做 Test user
    1. 開 console.cloud.google.com，揀返你設定呢個app嗰個project
    2. 左邊選單 →「APIs & Services」→「OAuth consent screen」
    3. 揀返上面個分頁/連結「Audience」或者「Test users」（介面版本唔同名可能唔同，搵住「Test users」呢個字）
    4. 撳「+ Add users」，貼返佢個email，撳「Save」
    呢步同第1步係兩件唔同嘅嘢，兩樣都要做——第1步係app自己嘅授權名單，呢步先係Google畀唔畀佢個Google戶口用呢個未verify嘅app。冇做呢步，佢撳「登入Google」會即刻被Google拒絕。
  3. 去 Google Drive 分享個資料夾畀佢
    1. 開你自己個 Google Drive（drive.google.com），用嗰個同你登入呢個app一樣嘅戶口
    2. 喺「我的雲端硬碟」根目錄搵「Warehouse Inventory Check Photos」呢個資料夾（你之前上傳Excel/相片嗰陣app自動幫你開嘅）
    3. 右擊個資料夾 →「共用」（Share）
    4. 貼返佢個email，右邊權限揀「編輯者」（Editor），撳「傳送」/「共用」
    要用返同一個email（同第1、2步一致），否則就算分享咗都連唔埋。
  4. 叫佢而家先第一次打開個app登入
    確保上面3步都做晒先叫佢撳link登入。如果佢之前已經試過登入（喺你未分享之前），佢個app會已經自己開咗一個屬於佢自己嘅新資料夾，見唔到你嘅資料——遇到呢種情況，等佢登入之後入「⚙」設定，撳「重新搜尋Drive資料夾」就救返。
🔄 Drive疑難排解
如果你係其他同事啱啱分享咗資料夾畀你，但個app見唔到佢哋嘅庫存資料（例如顯示「未有庫存資料」），撳呢個掣清走本機快取，重新搵一次啱嘅資料夾。
📄 上傳新庫存 Excel
會完全取代而家嘅 項資料，同埋清空所有已確認記錄（備註、確認狀態、自訂欄位內容等）。資料會存入你自己嘅私人Google Drive，唔會寫入呢個公開網頁，其他人打開呢個link都睇唔到。欄位要同原本格式一樣：Location、SKU Code、SKU Barcode、SKU Name、Qty、SKU Length、SKU Width、SKU Height、SKU Weight。
🔧 自訂欄位
新增欄位會出現喺每一條SKU/庫位記錄度。「跟庫位」= 每個庫位獨立填；「跟SKU」= 一個SKU填一次，全部庫位共用（好似量尺寸咁）。
